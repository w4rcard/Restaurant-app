# UI Design

For every major component consider:
- purpose and hierarchy
- spacing
- typography
- contrast
- iconography
- interaction states
- responsive behavior
- loading/empty/error states

Buttons, inputs, cards, navigation, tables, dialogs, dropdowns and forms should share a coherent visual language.
Avoid changing component styles independently when a shared token/component can solve it.
