# UX Design

- Make the primary action obvious.
- Minimize unnecessary steps.
- Use familiar interaction patterns.
- Provide immediate feedback for actions.
- Preserve user input on validation errors where possible.
- Make destructive actions clear.
- Design meaningful loading, empty, error, and success states.
- Keep navigation predictable.
- Never add friction merely for visual effect.
