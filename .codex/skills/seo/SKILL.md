# SEO

When relevant, check:
- semantic HTML
- title and description
- heading hierarchy
- canonical URL
- robots directives
- sitemap integration
- Open Graph/social metadata
- structured data when appropriate
- crawlable navigation
- image alt text
- performance and mobile usability

Do not keyword-stuff or add metadata that is not supported by page content.
