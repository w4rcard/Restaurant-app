# React

- Follow the project's React conventions.
- Keep components focused.
- Prefer composition over excessive prop branching.
- Avoid premature memoization; use it when evidence or component behavior warrants it.
- Keep effects for synchronization, not ordinary derived values.
- Avoid unnecessary state.
- Use stable keys.
- Preserve existing data-fetching/routing architecture.
- Check client/server boundaries in frameworks that support them.
