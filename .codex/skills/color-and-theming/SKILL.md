# Color and Theming

- Define semantic color tokens rather than scattering raw colors.
- Separate surface, text, border, accent, success, warning, and error roles.
- Maintain adequate contrast.
- Keep accent usage intentional.
- For dark mode, avoid simply inverting colors; establish appropriate surfaces and text contrast.
- Respect the project's existing theme architecture.
