# Visual Hierarchy

Use size, weight, spacing, contrast, alignment, grouping, and position deliberately.

Check:
- What should users notice first?
- What is the primary action?
- Are related elements visually grouped?
- Is secondary information subordinate?
- Is the page scannable at a glance?

Avoid making every element visually loud.
