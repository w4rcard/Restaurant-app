# API Integration

- Reuse the project's existing API client/data layer.
- Validate untrusted external data at boundaries.
- Handle loading, empty, error, retry, and timeout states appropriately.
- Avoid duplicate requests.
- Send only necessary data.
- Keep secrets server-side.
- Respect authentication and authorization.
- Do not invent API fields or behavior; inspect existing contracts.
