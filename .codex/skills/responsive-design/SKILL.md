# Responsive Design

- Design around content breakpoints, not device names alone.
- Test narrow and wide layouts.
- Prevent horizontal overflow.
- Reflow grids and navigation appropriately.
- Make controls touch-friendly.
- Ensure typography and spacing scale sensibly.
- Do not merely shrink desktop UI.
- Verify real interaction states at small widths.
