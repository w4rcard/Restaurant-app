# TypeScript

- Prefer precise types over `any`.
- Reuse existing domain types.
- Narrow unknown external data at boundaries.
- Avoid unnecessary type gymnastics.
- Keep public types understandable.
- Preserve strictness configured by the repository.
- Run the project's typecheck after meaningful type changes.
