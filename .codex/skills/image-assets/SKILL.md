# Image & Asset Optimization

- Use correctly sized responsive images.
- Prefer modern formats when supported by the stack.
- Avoid shipping huge source images for small displays.
- Lazy-load non-critical images.
- Reserve dimensions to reduce layout shift.
- Optimize SVGs without removing required accessibility semantics.
- Avoid duplicate assets.
- Load fonts deliberately and avoid excessive font weights.
