# CSS

- Reuse design tokens and component styles.
- Prefer modern layout primitives: flex, grid, container queries where appropriate.
- Avoid deeply nested selectors.
- Avoid `!important` unless genuinely necessary.
- Prefer transform/opacity for animation.
- Keep responsive rules close to the component/system they govern.
- Avoid duplicating equivalent styles.
- Respect existing CSS architecture.
