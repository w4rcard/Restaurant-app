# Design Audit

When asked to improve an existing page, inspect before editing.

Audit:
1. Layout and spacing
2. Visual hierarchy
3. Typography
4. Color/theme
5. Component consistency
6. Interaction states
7. Animations
8. Responsive behavior
9. Accessibility
10. Performance

Prioritize issues that materially affect usability or polish.
Make changes in coherent groups and verify the result.
Do not replace the design system simply because a different style is fashionable.
