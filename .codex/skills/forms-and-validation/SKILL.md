# Forms & Validation

- Use semantic labels and controls.
- Validate at appropriate boundaries.
- Give specific, actionable errors.
- Preserve valid user input after errors.
- Avoid validation that conflicts with server truth.
- Support keyboard and screen-reader interaction.
- Provide clear loading/submission states.
