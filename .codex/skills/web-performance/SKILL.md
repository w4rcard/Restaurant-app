# Web Performance

Check the relevant bottleneck before optimizing.

Priorities:
- reduce unnecessary JavaScript
- code-split/lazy-load appropriate routes or components
- optimize images and fonts
- prevent duplicate requests
- reduce render-blocking work
- minimize expensive renders and computations
- use caching appropriately
- avoid layout shift
- optimize critical rendering paths

Do not make speculative micro-optimizations. Preserve UX and accessibility.
