# Efficient Debugging

1. Reproduce or characterize the failure.
2. Capture the smallest useful error.
3. Locate the failing code/configuration.
4. Inspect surrounding implementation and direct dependencies.
5. Identify the likely root cause.
6. Make the smallest safe fix.
7. Reproduce and run focused regression checks.

Prefer evidence over guesses. Use one informative diagnostic over many exploratory commands.
