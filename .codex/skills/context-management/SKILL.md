# Context Management

1. Identify the exact goal.
2. Locate likely files with shallow listing and targeted search.
3. Inspect only relevant sections.
4. Form a working hypothesis.
5. Edit the smallest necessary scope.
6. Verify.
7. Expand scope only when evidence requires it.

Ignore node_modules, .git, dist, build, caches, generated/vendor files unless relevant.
Filter large command output at the source.
Ask a focused question when ambiguity blocks safe work instead of exploring the entire repository.
