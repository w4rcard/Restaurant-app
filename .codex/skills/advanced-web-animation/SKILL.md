# Advanced Web Animation

Use advanced effects only when they improve comprehension or perceived quality.

Patterns:
- scroll-driven reveals
- subtle parallax
- spring-based interaction
- shared-element/page transitions
- modal and drawer motion
- list enter/exit choreography
- magnetic or cursor-following effects when appropriate

Rules:
- Progressive enhancement: the UI must work without the effect.
- Respect reduced-motion preferences.
- Avoid blocking input or navigation.
- Avoid excessive cursor tracking and continuous JavaScript animation.
- Prefer CSS scroll-driven animation when browser support and project constraints allow it.
- Keep effects consistent with the site's visual language.
