# Project Planning

For multi-file tasks:
- State the requested outcome.
- Identify the smallest set of workstreams/files.
- Note constraints and existing conventions.
- Make a short ordered plan.
- Verify assumptions before expanding scope.
- Update the plan only when evidence changes the implementation.

Do not create long speculative plans for small tasks.
