# Architecture

- Understand current architecture before introducing a new pattern.
- Prefer the simplest design that meets current requirements.
- Reuse existing layers and abstractions.
- Separate UI, domain logic, data access, and configuration when complexity warrants it.
- Avoid premature abstraction.
- Avoid large rewrites when incremental change is viable.
