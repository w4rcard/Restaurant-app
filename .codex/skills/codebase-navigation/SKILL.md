# Codebase Navigation

- Start with a shallow repository structure.
- Find entry points and relevant configuration only as needed.
- Search exact feature names, symbols, routes, components, errors, or config keys.
- Follow direct imports/references.
- Stop when the implementation path is clear.
- Do not inspect unrelated modules or generated/dependency directories.
- Report relevant files and why they matter rather than reproducing large sections.
