# Web Design

Build interfaces that feel intentional, modern, and production-ready.

Priorities:
- Clear visual hierarchy.
- Consistent spacing and sizing system.
- Strong typography hierarchy.
- Restrained, coherent color system.
- Consistent border radius, shadows, borders, and icon treatment.
- Clear primary/secondary actions.
- Good empty, loading, error, success, hover, focus, and disabled states.
- Responsive behavior from mobile through desktop.
- Avoid excessive gradients, glass effects, giant headings, random rounded cards, and decorative elements without purpose.
- Do not redesign existing UI blindly: inspect its visual language first and extend it consistently.
- Prefer reusable design tokens/components over one-off styling.
